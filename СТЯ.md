# Monitor - запуск на Windows

## 1. апуск сервера Monitor

важды нажмите **START.cmd** в папке проекта `D:\Projects\monitor`.

ервый запуск требует интернета, Python **3.13** с Python Launcher и Node.js LTS.

ашборд: http://127.0.0.1:5173/
нвентаризация: http://127.0.0.1:5173/inventory

Сервер слушает порт **8000** на всех интерфейсах (`0.0.0.0`).

## 2. де взять токен

ткройте `backend\.env` на сервере Monitor через локнот.

Там строка: `SECRET_KEY=8abd851dacbd4ccd...`

Скопируйте **только значение после `=`**. то и есть токен.

## 3. EXE-клиент на этом же 

Скопируйте `agent\dist\MonitorClient.exe` в `C:\MonitorClient`.
апустите EXE двойным кликом:

- дрес сервера: `http://127.0.0.1:8000`
- Токен: нажмите "ставить из буфера" (скопируйте из `backend\.env`)
- апка сертификатов: выберите через кнопку
- Службы: `W32Time, Spooler`

ядом с EXE появятся `config.yaml` и `TOKEN.txt`.

## 4. EXE-клиент на другом Windows Server

Скопируйте ТЬ `MonitorClient.exe`. Python не нужен.

 мастере:
- дрес: `http://192.168.19.134:8000` (IP сервера Monitor)
- Токен: скопируйте с сервера Monitor, нажмите "ставить из буфера"

сли клиент не появляется:
- роверьте ping до сервера Monitor
- роверьте firewall на порт 8000
- роверьте, что токен совпадает с `SECRET_KEY`

## 5. оновая служба (от администратора)

```cmd
cd /d C:\MonitorClient
MonitorClient.exe install
MonitorClient.exe start
```

| оманда | ействие |
|---|---|
| `status` | Состояние |
| `stop` | становить |
| `start` | апустить |
| `remove` | далить |
| `--configure` | зменить настройки |

## 6. то показывается

- Сертификаты: PEM/CER/CRT/DER, шкала срока
- иски: занято/свободно, шкала заполнения
- Службы: зеленый=запущен, красный=остановлен
- ремя: разница часов клиента и сервера

## 7. оиск клиентов в сети

http://127.0.0.1:5173/inventory -> укажите диапазоны:
```
192.168.1.0/24
10.10.20.0/24
```

а клиенте PowerShell от администратора:
```powershell
New-NetFirewallRule -DisplayName "Monitor discovery" -Direction Inbound -Protocol TCP -LocalPort 19443 -RemoteAddress 192.168.19.134 -Action Allow
```

## 8. сли не запускается

- шибка 500: перезапустите START.cmd
- шибка 401: проверьте токен
- устой список: подождите 30 секунд
- ет сертификатов: проверьте папку и права

е удаляйте `backend\monitoring.db`. е передавайте `backend\.env` и `config.yaml` посторонним.
