# Monitor - запуск на Windows

## 1. Запуск сервера Monitor

Дважды нажмите START.cmd в папке D:\Projects\monitor.

Первый запуск: Python 3.13 и Node.js LTS.

Дашборд: http://127.0.0.1:5173/
Инвентаризация: http://127.0.0.1:5173/inventory

Сервер на порту 8000, доступен из локальной сети.

## 2. Где взять токен

Откройте backend\.env через Блокнот. Там: SECRET_KEY=...

Скопируйте только значение после =. Это и есть токен.

## 3. EXE-клиент на этом же ПК

Скопируйте agent\dist\MonitorClient.exe в C:\MonitorClient.
Запустите двойным кликом.

В мастере:
- Адрес: http://127.0.0.1:8000
- Токен: нажмите "Вставить из буфера" (скопируйте из backend\.env)
- Папка сертификатов: кнопка "Выбрать папку"
- Службы: W32Time, Spooler

Рядом с EXE: config.yaml и TOKEN.txt.

## 4. EXE-клиент на другом Windows Server

Скопируйте ТОЛЬКО MonitorClient.exe. Python не нужен.

В мастере:
- Адрес: http://IP-СЕРВЕРА:8000
- Токен: скопируйте с сервера Monitor, нажмите "Вставить из буфера"

Если клиент не появляется:
- ping до сервера Monitor
- порт 8000 в firewall сервера
- токен совпадает с SECRET_KEY

## 5. Фоновая служба (cmd от администратора)

cd /d C:\MonitorClient
MonitorClient.exe install
MonitorClient.exe start

Команды: status, stop, start, remove, --configure

## 6. Что показывается

Сертификаты: PEM/CER/CRT/DER, шкала срока (желтый - до 30 дней, красный - просрочен)
Диски: занято/свободно, шкала заполнения
Службы: зеленый=запущен, красный=остановлен
Время: разница часов клиента и сервера

## 7. Поиск клиентов в сети

На http://127.0.0.1:5173/inventory укажите:
192.168.1.0/24
10.10.20.0/24

На клиенте PowerShell от администратора:
New-NetFirewallRule -DisplayName "Monitor discovery" -Direction Inbound -Protocol TCP -LocalPort 19443 -RemoteAddress IP-СЕРВЕРА -Action Allow

## 8. Если не запускается

Ошибка 500: перезапустите START.cmd
Ошибка 401: проверьте токен
Пустой список: подождите 30 секунд
Нет сертификатов: проверьте папку и права

Не удаляйте backend\monitoring.db.
Не передавайте backend\.env и config.yaml посторонним.
